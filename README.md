# 🏛️ Zamanın İzleri - Klasik Bilgi Portalı

Bu proje, antik medeniyetlerin mirasını, felsefeyi ve tarihi dijital dünyaya taşıyan, klasik ve zamansız bir tasarıma sahip statik bir web sitesidir. Karmaşık modern tasarımlar yerine okunabilirliği, sadeliği ve bilgiye odaklanmayı ön planda tutan geleneksel bir web mimarisi kullanılarak geliştirilmiştir.

## 🚀 Özellikler

* **Klasik ve Sade Tasarım:** Kullanıcıyı yormayan yumuşak renk paleti (toprak tonları) ve serif font (Georgia) kullanımı.
* **Geleneksel Sayfa Düzeni:** Üst bilgi (Header), navigasyon menüsü, ana içerik alanı, yan menü (Sidebar) ve alt bilgi (Footer) barındıran standart web iskeleti.
* **Temiz Kod Mimarisi:** HTML, CSS ve JavaScript dosyalarının birbirinden tamamen ayrılarak (`Separation of Concerns` prensibi) modüler bir yapıda tutulması.
* **Hızlı ve Sunucusuz:** Hiçbir veritabanı veya arka plan sunucusuna ihtiyaç duymadan, doğrudan tarayıcı üzerinde saniyeler içinde çalışır.

## 📂 Dosya Yapısı

Proje, temel web geliştirme standartlarına uygun olarak 3 ana dosyadan oluşmaktadır:

\`\`\`text
zamanin-izleri/
├── index.html   # Sitenin iskeleti ve içeriklerin bulunduğu ana dosya
├── style.css    # Sitenin renk, font ve yerleşim ayarlarını (makyajını) tutan dosya
└── script.js    # İleride eklenebilecek dinamik özellikler için altyapı dosyası
\`\`\`

## 💻 Kurulum ve Kullanım

Bu projeyi çalıştırmak için herhangi bir paket program (Node.js vb.) veya sunucu kurmanıza **gerek yoktur**.

1. Proje dosyalarını bilgisayarınıza indirin veya klonlayın.
2. Klasörün içindeki `index.html` dosyasına çift tıklayın.
3. Site varsayılan web tarayıcınızda (Chrome, Safari, Firefox vb.) anında açılacaktır.

## 🛠️ Kullanılan Teknolojiler

* **HTML5:** Semantik web etiketleri kullanılarak oluşturulmuş sağlam iskelet.
* **CSS3:** Flexbox kullanılarak tasarlanmış esnek yan yana yerleşim (Sidebar ve Content) ve klasik stil kodlamaları.
* **Vanilla JavaScript:** Dışa bağımlılık olmadan eklenmiş temel script altyapısı.
